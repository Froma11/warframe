# Warframe Market Analytics & Private Operator Portal

> Высокопроизводительный биржевой терминал аналитики мистификаторов (Arcanes) Warframe с кинематографичным дизайном Orokin / Void Terminal, отслеживанием реальных сделок (Closed Transactions API v1), динамическим скрапером и приватным терминалом заметок оператора.

---

## ⚡ Особенности архитектуры

* **Real Market Closed Deals Engine:**
  * Синхронизация реальных закрытых сделок через Warframe Market API (`statistics_closed`) с разбивкой по рангам (Ранг 0 и Максимальный ранг) за последние 48 часов и 90 дней.
  * Точные медианные цены, объёмы закрытых сделок, глубина стакана и скорость сбыта (deals/hour).
  * Динамический учет максимального ранга мистификатора (R3 / R5).
* **Кинематографичный Orokin HUD & Cockpit:**
  * Аутентичная темная цветовая гамма, локальные шрифты **Raleway** и **JetBrains Mono**.
  * Интерактивный нативный SVG-график с **Void Energy Beam** (многослойный Bloom-эффект).
  * **Живой Scrubbing:** мгновенный пересчет главной цены и дельты при ведении курсора по графику.
  * Скользящий индикатор выбора периодов (**Sliding Pill**: 24h, 7d, 30d, 90d).
  * **0 ms отклик** при переключении рангов (клиентский кэш истории).
  * Торговая аналитическая лента (скорость сбыта, спред стакана, волатильность).
* **Каталог Sedna & Пагинация:**
  * 170+ мистификаторов с постраничным переходом (24 / 48 / 96 на страницу), быстрым поиском и сортировкой.
* **Приватный терминал Earth:**
  * Защищенный операторский профиль с персональными заметками и отслеживанием целей.
* **Gatekeeper & Безопасность:**
  * JWT-аутентификация в `HttpOnly`-cookie, хэширование паролей bcrypt.
  * Фоновый воркер актуализации данных каждые 15 минут с защитой от rate-limit (WAL-режим SQLite).

---

## 🛠 Стек технологий

* **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, локальные шрифты (Raleway, JetBrains Mono).
* **Backend:** Node.js, Express, TypeScript, SQLite3 (WAL mode).
* **Data Provider:** Warframe Market Official API.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
cd client && npm install
cd ../server && npm install
cd ..
```

### 2. Сборка проекта
```bash
npm run build
```

### 3. Запуск сервера
```bash
npm start
```
Сервер запустится на порту `4000` (http://localhost:4000).
